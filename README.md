# 🎬 VideoSearch 影片標題暨封面搜尋程式 v1.0

由 **建生工坊（Chien-Sheng Workshop）** 開發的桌面端自動化影視資料檢索與封面歸檔工具。

本程式全程採用 **Gemini 3.8 Flash（高思考程度）** 搭配 **Antigravity IDE AI 助手（Gemini 3.8 Flash High）** 進行系統架構設計與除錯開發，內建完整 19 個 Python 模組，支援高效檢索與二次開發擴充。

---

## ✨ 核心功能亮點

* **🌐 全球多站點聚合檢索**：輸入影片或動畫關鍵字，秒速匯流 TMDB、Wikipedia、Bing 等全球影視資料庫，一次列出完整系列作品與詳細資訊。
* **🏷️ 聲優／演員名單與歸檔格式秒整理**：自動抓取完整聲優與演員名單並支援一鍵勾選，內建「歸檔字尾快速切換」與字數上限設定，一鍵複製整齊的「標題＋片名＋演員」格式。
* **🖼️ 原廠高清封面＋全套劇照相簿一鍵落地**：不只抓取單張主封面，連同作品附屬的整套預覽劇照相簿（單部作品最高可載入數十至上百張高畫質劇照）與 JSON 中繼資料，按下「一鍵存檔」自動在電腦本機建立資料夾整齊歸檔。
* **🤖 內附完整 19 個 Python 原始碼・支援 AI 自由二次開發**：壓縮包內直接保留完整 19 個 Python 專案原始碼檔案（包含 `main.py`、`web_searcher.py`、`ai_extractor.py` 等模組）。搭配 Antigravity IDE 與 Gemini 3.8 Flash High 模型，即可自由修改介面、調整命名規則或擴充新站點。
